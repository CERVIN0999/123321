# Калькулятор скидки

Консольная программа на C# рассчитывает итоговую цену товара после скидки.

## Назначение
Быстрый расчёт стоимости товара со скидкой.

## Возможности
- ввод цены и процента скидки;
- проверка корректности ввода;
- вывод результата с двумя знаками после запятой.

## Требования
- .NET 8.0 (сверить с `TargetFramework` в `.csproj`);
- Visual Studio или терминал.

## Запуск
1. Откройте `DiscountCalculator.sln`.
2. Выберите проект `DiscountCalculator`.
3. Нажмите `Ctrl+F5`.

Через терминал:
```bash
dotnet run
Примеры
Ввод: 1000, 15
Вывод: Результат: 850.00

Ввод: 2500, 20
Вывод: Результат: 2000.00
