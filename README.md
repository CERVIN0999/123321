# Калькулятор скидки

Консольная программа на C# рассчитывает цену товара после скидки.

## Назначение
Быстрый расчёт итоговой стоимости товара со скидкой.

## Возможности
- ввод цены;
- ввод процента скидки;
- проверка ввода;
- вывод результата с двумя знаками.

## Требования
- .NET 8.0 (сверить с TargetFramework в .csproj);
- Visual Studio или терминал.

## Запуск
1. Открыть `DiscountCalculator.sln`.
2. Выбрать проект `DiscountCalculator`.
3. Нажать `Ctrl+F5`.
Или в терминале: `dotnet run`.

## Примеры
Ввод: `1000`, `15`  
Вывод: `Результат: 850.00`

Ввод: `2500`, `20`  
Вывод: `Результат: 2000.00`
